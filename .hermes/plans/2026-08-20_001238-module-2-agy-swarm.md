# Module 2 — AGY Swarm Implementation Plan

> **Planning only.** No writer, worktree, package install, DB, commit, push, merge, or deployment is authorized by this artifact.

**Goal:** Build the smallest public Knowledge Repository + Expert Directory: publication/expert discovery, filters, stable cursor pagination, explainable partner suggestions, no private-record leakage.

**Architecture:** Two source-of-truth services, two PostgreSQL databases. `knowledge-service` owns publications/topics; `organization-service` owns organizations/expert profiles/expertise. Frontend integrates only after HTTP contracts stabilize. AGY Swarm uses native Git worktrees plus AGY stream output; no custom scheduler, queue, workflow DB, dashboard, Elasticsearch, graph DB, Kafka, Redis, vectors, ORCID, or Scopus.

---

## Ponytail decisions

1. **OPEN-03 deferred safely:** Module 2 MVP is read-only public discovery. No create/edit/publish/moderation API. Synthetic dev fixtures only.
2. **OPEN-04 dev default:** PostgreSQL native text search; deterministic shared-topic matching.
3. **No standalone `/matches`:** suggestions live on expert detail.
4. **No API gateway:** frontend server/BFF calls each backend directly.
5. **No shared package:** service-local DTOs until duplication becomes measurable drift.
6. **No swarm supervisor code:** Git/process/NDJSON are sufficient.

Upgrade search only when representative p95 exceeds 300 ms or agreed relevance fixtures fail.

## Wave 0 — Host contract baseline

**Execution:** sequential; no AGY writer.

Define frozen public contracts in the plan packet, not a new shared package:

```text
PublicationSummary
PublicationDetail
ExpertSummary
ExpertDetail
MatchReason
CursorPage<T>
```

Contract rules:

- IDs and references are opaque strings.
- `limit`: default 20, maximum 50.
- cursor encodes stable sort tuple, not offset.
- malformed cursor returns 400.
- unknown/private detail returns 404.
- list/search/matches apply `PUBLIC` predicate before pagination/ranking.
- match response contains shared reason IDs/labels; no fake percentage.
- list response never hydrates cross-service detail.

Host creates integration branch/worktree from clean accepted SHA:

```bash
git fetch origin
git worktree add ../vnru-m2-int -b int/m2/discovery <BASE_SHA>
```

## Wave 1 — Parallel backend foundations

### AGY-01 Slice K1

**Mission:** Boot `knowledge-service`; migrate/seed public and private publication records; expose bounded list/detail.

**Minimum models:**

```text
Publication
KnowledgeTopic
PublicationTopic
PublicationAuthorRef
```

`Publication`: title, abstract, type, language, year, country, organizationRef, visibility, version, timestamps.

**Routes:**

```text
GET /api/v1/publications
GET /api/v1/publications/:id
```

**One focused check must prove:** private records are absent from list and inaccessible by ID; cursor ordering remains stable for equal timestamps.

### AGY-02 Slice E1

**Mission:** Boot `organization-service`; migrate/seed public/private organizations and experts; expose bounded list/detail/matches.

**Minimum models:**

```text
Organization
ResearcherProfile
ExpertiseArea
ResearcherExpertise
```

**Routes:**

```text
GET /api/v1/organizations
GET /api/v1/experts
GET /api/v1/experts/:id
GET /api/v1/experts/:id/matches
```

**Matching:** shared expertise count descending, stable expert ID ascending. Exclude self/private profiles. Return matching expertise as reasons.

**One focused check must prove:** private profile never appears in list/detail/matches; ranking and reasons are deterministic.

### AGY-03 read-only review

Check DTO usability, cursor URL shape, frontend error/empty needs. No files changed.

### AGY-04 read-only security review

Check scope predicate placement, enumeration, cursor tampering, cross-service ownership. No files changed.

### Host Wave 1 gate

For each backend independently:

```bash
pnpm test -- --runInBand
pnpm test:e2e -- --runInBand
pnpm build
pnpm exec eslint "{src,apps,libs,test}/**/*.ts"
pnpm exec prisma migrate status
git diff --check
```

Additional proof:

1. Apply migrations to empty service DB.
2. Seed twice.
3. Assert business-key counts unchanged.
4. Start service; smoke public routes.
5. Reject out-of-allowlist files.
6. Commit each slice on its own branch.
7. Integrate sequentially into `int/m2/discovery`; rerun both service gates.

## AGY invocation contract

Each writer gets one worktree, one branch, one prompt, maximum 8 allowed files, 20-minute internal time box, 25-minute outer timeout.

```bash
agy --new-project \
  --mode accept-edits \
  --effort medium \
  --output-format stream-json \
  --json-schema <RESULT_SCHEMA> \
  --log-file <LANE.ndjson> \
  --print-timeout 25m \
  --print <PROMPT>
```

Result schema:

```json
{
  "type": "object",
  "additionalProperties": false,
  "required": ["status", "changed", "tests", "residual"],
  "properties": {
    "status": { "enum": ["DONE", "BLOCKED"] },
    "changed": { "type": "array", "items": { "type": "string" } },
    "tests": { "type": "array", "items": { "type": "string" } },
    "residual": { "type": "array", "items": { "type": "string" } }
  }
}
```

AGY output is progress evidence only. Host diff/tests are completion evidence.

Stop entire writable wave on:

- overlapping allowlist discovered;
- shared package/schema/registry/public contract edit;
- out-of-scope path;
- quota/auth failure;
- timeout before inspecting preserved diff;
- migration ambiguity;
- requested architecture beyond approved MVP.

No automatic retry, commit, push, merge, or deploy.

## Definition of done

- Public publication/expert list/detail work anonymously.
- Filters and stable cursor work.
- Private records return no discoverable result through list, ID, search, match, or frontend.
- Topics/authors/organizations use references without cross-service DB access.
- Suggestions are deterministic and explainable.
- Seeds are idempotent.
- Empty-DB migrations pass independently.
- Full service/frontend gates pass.
- Desktop/mobile browser checks pass.
- Integration branch is clean and reviewable.
- Graph and bounded packs are current.
