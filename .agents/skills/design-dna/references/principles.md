# Principles

1. **Readability before density: normal content is at least 16px; metadata is at least 14px.**
2. **One multilingual type system: Vietnamese, Russian, and English must retain the same hierarchy and metrics.**
3. **Operational UI is calm and explicit; public UI may be expressive but must not destabilize layout.**
4. **Use shared tokens and primitives; route-specific magic numbers are drift.**
5. **Preview capability must look like preview capability, never fake production state.**
