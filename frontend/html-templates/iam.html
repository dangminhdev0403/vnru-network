Permissions & Resource Scope

Permission name không thay thế resource-level authorization.

IAM.USER.READ

Đọc account/user theo scope quản trị được cấp.

GRANT.PROPOSAL.READ

Đọc proposal nếu resource nằm trong scope/context.

REVIEW.ASSIGNMENT.READ

Reviewer chỉ thấy assignment được phân công.

PROJECT.PROJECT.READ

Project access phụ thuộc organization/project scope.

Anti-pattern: không dùng role === "ADMIN" hoặc dữ liệu localStorage làm security boundary.
